## Version 1.0.0

First stable evidence-informed release.

Major additions

- Evidence-based recommendation framework
- Explainable dashboard
- ORF validation
- Protein alignment and relatedness
- Protein continuity
- Shared observation model
- Biological findings
- Assembly-level reasoning

This release establishes the core SegPick architecture.
Future releases are expected to extend the evidence framework rather than redesign it.
