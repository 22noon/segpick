# Dashboard Refinement – Phase 5

This refinement improves navigation and readability within the candidate-scoped Evidence tab.

## Changes

- Added a sticky Evidence navigator linking directly to Structural integrity, Reference compatibility, Read evidence, and ORF structural evidence.
- Converted the navigator to a horizontal jump bar on narrower screens.
- Added stable section anchors for all four evidence sections.
- Reused the dashboard tab-routing behaviour so evidence links activate the Evidence tab before scrolling.
- Corrected explanatory disclosure styling so “How the score is calculated” and “How this differs from structural integrity” use the full available width instead of inheriting the multi-column evidence-summary layout.

No evidence calculation, ranking, or biological interpretation logic was changed.
