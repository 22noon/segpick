# Dashboard Refinement – Phase 4

This milestone improves discovery and navigation of candidate visualizations.

## Changes

- Added a dedicated **Protein relatedness** visualization to the Plots tab.
- Replaced the detailed protein alignment inside ORF structural evidence with a direct **View protein relatedness** link.
- Retained BLASTX-anchored ORF details in Evidence because they are biological evidence rather than merely presentation.
- Added a sticky visualization navigator for immediate access to:
  - candidate comparison
  - shared-reference alignment
  - closest-reference alignment
  - protein coordinates
  - protein relatedness
  - read coverage
- Added a compact horizontal navigator layout for smaller screens.

No ranking, scoring, evidence generation, or biological interpretation logic was changed.
