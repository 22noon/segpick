# Changelog

## 0.1.0

First official SegPick release.

- Renamed the project and Python package from SegPick to SegPick.
- Added `segpick run` and `segpick doctor` subcommands.
- Added YAML configuration support.
- Added precedence: defaults < YAML < command line.
- Added explicit `--no-*` boolean overrides.
- Added `provenance.yml` output.
- Preserved alignment, containment analysis, dashboard, and FASTA download features.
