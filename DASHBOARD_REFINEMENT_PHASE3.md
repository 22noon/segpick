# Dashboard Refinement Phase 3

## Gene-level comparison versus candidate-level inspection

The gene dashboard now distinguishes content that compares all candidates from content that describes the currently selected candidate.

The navigation order is:

1. Summary
2. Comparison
3. Evidence
4. Biological reasoning
5. Plots
6. Downloads
7. Expert

The **Comparison** tab contains the evidence table because that table is a gene-level, side-by-side comparison of every candidate. It remains stable when the selected candidate changes.

The **Evidence** tab now contains candidate-scoped evidence assessments and detailed evidence channels for the selected candidate.

This is a presentation-only change. Ranking, evidence generation, reasoning, and recommendations are unchanged.
