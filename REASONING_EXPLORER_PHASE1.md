# Reasoning Explorer – Phase 1

This milestone adds a candidate-aware reasoning explorer to the Biological reasoning tab.

## Included

- Sticky reasoning navigation on desktop and a horizontal jump bar on narrow screens.
- A candidate-specific reasoning path from evidence assessments through cross-evidence findings, scenarios, hypotheses, and recommendation context.
- Direct links to each reasoning layer and back to the underlying evidence.
- Reuse of existing view-model objects; no reasoning or ranking logic is duplicated in the dashboard.

## Scope

This is a navigation and traceability milestone. It does not alter scoring, rule evaluation, biological inference, or candidate ranking.
