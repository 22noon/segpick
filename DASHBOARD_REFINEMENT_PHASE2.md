# Dashboard Refinement – Phase 2

The gene dashboard now uses six top-level tabs:

- Summary
- Evidence
- Biological reasoning
- Plots
- Downloads
- Expert

## Downloads

The Downloads tab contains:

- Download selected sequences
- Selected candidate sequence
- Copy sequence
- Download individual candidate FASTA

## Expert

The Expert tab contains the rule explorer and any technical sections that are not assigned to another user-facing tab.

This change affects dashboard presentation only. Ranking and biological reasoning are unchanged.
