# Reference Compatibility Knowledge Expansion

This milestone adds biological interpretation for departures from the expected structure represented by the closest reference. These scenarios and hypotheses are explanatory only and do not alter candidate ranking.

## New scenarios

- Internal sequence absent from the closest reference
- Read-supported sequence absent from the closest reference
- Possible misassembled internal insertion
- Possible reference-relative rearrangement
- Possible reference-relative inversion
- Possible duplicated or repeated reference region
- Internal expected reference sequence is absent

## Cross-channel distinction

An unsupported internal candidate interval is interpreted differently according to read evidence:

- Complete ORF read coverage supports a provisional biological insertion or reference mismatch interpretation.
- An internal read-coverage interruption supports concern for a misassembled or chimeric insertion.

## New aggregated hypotheses

- Possible reference-relative structural variation
- Possible reference-relative misassembly
- Closest reference may not represent the isolate structure

All language is deliberately cautious. Reference incompatibility is not treated as proof of misassembly or novel biology without supporting evidence from reads and additional references.
